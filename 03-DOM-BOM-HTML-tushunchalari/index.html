1-bo'lim

DOM — sahifaning daraxti

Har bir veb-sahifa — bu ichma-ich joylashgan elementlar daraxti. Quyidagi tugmani bosib, daraxtning har bir "shoxini" ajratib ko'ring.

DOM daraxti

<html>
<body>
<h1>
<button>

Nima uchun kerak?

DOM — JavaScript uchun "xarita". Bu xarita bo'lmasa, JavaScript sahifada nima borligini va qayerga "qo'l tekkizishni" bilmaydi.

BOM — brauzerning o'zi

DOM — sahifa ICHI. BOM — brauzerning O'ZI (oyna o'lchami, xabar oynasi, manzil).
